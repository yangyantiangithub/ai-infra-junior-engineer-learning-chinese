## 如何使用这些资源

### 日常工作中
- 将速查表加入书签，方便快速查找命令
- 打印常用命令并放在工作区附近
- 定期练习命令以形成肌肉记忆

### 学习过程中
- 按顺序跟随初级阅读路径
- 每个类别至少完成一个资源
- 做笔记并尝试示例
- 与学习小组分享有趣的发现

### 做项目时
- 搭建开发环境时参考 tools.md
- 使用速查表快速找到正确的命令
- 查阅阅读清单以深入理解概念

## 资源质量标准

评估资源时，考虑：
- **准确性**：信息是否正确且最新？
- **相关性**：是否适用于初级 AI 基础设施工程师角色？
- **可获取性**：是否免费或价格合理？
- **深度**：是否提供了足够的细节？
- **声誉**：来源是否可信？

---

## 需要帮助？

如果资源过多让你不知所措：

1. **从速查表开始**——它们是快速见效的选择
2. **跟随初级阅读路径**——经过精心策划和顺序编排
3. **每个类别选一个资源**——不要试图全部消化
4. **注重动手实践**——理论 + 实践 = 精通
5. **询问社区**——查看 `community/FAQ.md` 了解如何获取帮助
