# Module 006: 推荐阅读和资源

## 官方文档

### Kubernetes 官方文档
- **主要文档**: https://kubernetes.io/docs/
  - 涵盖所有 Kubernetes 主题的全面、权威来源
  - 结构清晰，包含概念、任务、教程和参考章节

- **概念指南**: https://kubernetes.io/docs/concepts/
  - 深入了解 Kubernetes 架构和设计
  - 理解决策背后"为什么"的必备阅读

- **任务和教程**: https://kubernetes.io/docs/tasks/
  - 常见操作的分步指南
  - 附有说明的动手示例

- **kubectl 参考**: https://kubernetes.io/docs/reference/kubectl/
  - 完整的 kubectl 命令参考
  - 日常运维的必备工具

- **API 参考**: https://kubernetes.io/docs/reference/kubernetes-api/
  - 所有 API 资源的详细文档
  - 编写 manifest 时很有用

### Helm 文档
- **官方 Helm 文档**: https://helm.sh/docs/
  - Helm 3 的完整指南
  - Chart 开发最佳实践

- **Chart 最佳实践**: https://helm.sh/docs/chart_best_practices/
  - 创建生产就绪 chart 的指南
  - 命名约定、模板和 values

- **Chart 模板指南**: https://helm.sh/docs/chart_template_guide/
  - Helm 中 Go 模板的深入指南
  - 函数、管道和流程控制

## 书籍

### 入门到中级

**"Kubernetes in Action" by Marko Luksa (第 2 版)**
- Kubernetes 的全面介绍
- 附有图表的优秀讲解
- 全书贯穿动手示例
- 非常适合初级工程师

**"Kubernetes: Up and Running" by Kelsey Hightower, Brendan Burns, Joe Beda**
- 由 Kubernetes 共同创始人撰写
- 实践驱动的方法
- 理解核心概念的绝佳读物
- 免费在线阅读: https://www.oreilly.com/library/view/kubernetes-up-and/9781098110192/

**"The Kubernetes Book" by Nigel Poulton**
- 易于阅读和理解
- 随 Kubernetes 新版本定期更新
- 适合快速参考
- 包含视频内容

### 高级

**"Programming Kubernetes" by Michael Hausenblas, Stefan Schimanski**
- 用于构建 operator 和自定义控制器
- 深入探讨 Kubernetes API
- 高级自动化的必备读物

**"Production Kubernetes" by Josh Rosso, Rich Lander, Alex Brand, John Harris**
- 专注于生产环境中运行 Kubernetes
- 深入探讨安全、网络、存储
- 真实世界的模式和最佳实践

**"Kubernetes Patterns" by Bilgin Ibryam, Roland Huß**
- 云原生应用的设计模式
- 常见问题的可复用解决方案
- 架构指导

## 学习路径推荐

### 初学者 (0-3 个月)
1. 从官方文档教程开始
2. 完成 "Kubernetes in Action" 书籍
3. 观看 TechWorld with Nana YouTube 课程
4. 在 Play with Kubernetes 上练习
5. 完成所有 Module 006 练习

### 中级 (3-6 个月)
1. 使用 Minikube 设置本地集群
2. 部署多层应用
3. 学习 "Kubernetes: Up and Running"
4. 完成 KodeKloud 实验
5. 为真实项目构建 Helm chart

### 高级 (6+ 个月)
1. 阅读 "Programming Kubernetes"
2. 为 Kubernetes 项目做贡献
3. 构建自定义 operator
4. 考取 CKA 认证
5. 学习服务网格 (Istio, Linkerd)

## 有效学习的技巧

1. **动手实践**: 理论很重要，但实践是关键
2. **构建真实项目**: 部署实际应用，而不仅仅是示例
3. **加入社区**: 提问、帮助他人、做出贡献
4. **保持与时俱进**: Kubernetes 发展迅速；关注更新
5. **记录学习**: 保留笔记和示例供参考
6. **教授他人**: 巩固理解的最佳方式
7. **勇于试错**: 通过修复自己制造的问题来学习
8. **阅读源代码**: 理解底层工作原理
9. **参加见面会**: 与其他从业者交流
10. **保持耐心**: Kubernetes 很复杂；掌握需要时间
