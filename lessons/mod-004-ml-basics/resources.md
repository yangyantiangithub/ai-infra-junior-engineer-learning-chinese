# Module 004 — ML 基础资源

## 基础书籍

- **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow（第 3 版）**，作者 Aurélien Géron。最受推荐的从业者入门书籍。涵盖从经典 ML 到深度学习，配有代码示例。
- **Pattern Recognition and Machine Learning**，作者 Christopher Bishop。偏数学理论的经典之作。在实践过几个模型后阅读以理解理论。
- **The Hundred-Page Machine Learning Book**，作者 Andriy Burkov。正如书名所说。适合入门了解。
- **Designing Machine Learning Systems**，作者 Chip Huyen。关注 ML 系统工程而非算法；是 AI 基础设施岗位的基础读物。

## 在线课程

- **Andrew Ng 的 Machine Learning Specialization**（Coursera）。历史上观看人数最多的 ML 课程。2022 年更新为使用 Python（原为 Octave）。适合从这里开始。
- **Fast.ai Practical Deep Learning for Coders** — [course.fast.ai](https://course.fast.ai/)。自上而下的方法；先实践，后理论。与 Ng 的课程互补。
- **MIT 6.036 Introduction to Machine Learning** — 在 OCW 上免费提供。更加严谨。
- **Hugging Face NLP Course** — [huggingface.co/learn/nlp-course](https://huggingface.co/learn/nlp-course)。免费、现代化、动手实践的 transformers 课程。

## 需要了解的库

- **scikit-learn** — [scikit-learn.org](https://scikit-learn.org/)。经典的 ML 库标准。阅读其文档；它本身也是教学参考。
- **PyTorch** — [pytorch.org/tutorials](https://pytorch.org/tutorials/)。研究领域以及日益增长的生产领域中占主导地位的深度学习框架。
- **TensorFlow / Keras** — [tensorflow.org/tutorials](https://www.tensorflow.org/tutorials)。仍然常见，尤其是在移动/边缘部署中。
- **Hugging Face Transformers** — [huggingface.co/docs/transformers](https://huggingface.co/docs/transformers/)。用于 NLP/CV/音频的预训练模型。

## ML 系统参考文献

- **Rules of Machine Learning** by Google — [developers.google.com/machine-learning/guides/rules-of-ml](https://developers.google.com/machine-learning/guides/rules-of-ml)。43 条简短规则。必读内容。
- **Hidden Technical Debt in Machine Learning Systems**（Sculley 等，NeurIPS 2015）— [papers.nips.cc/paper/2015/file/86df7dcfd896fcaf2674f757a2463eba-Paper.pdf](https://papers.nips.cc/paper/2015/file/86df7dcfd896fcaf2674f757a2463eba-Paper.pdf)。"ML 是 5% 的 ML 和 95% 的胶水代码" 这一说法的原始出处。
- **Reliable Machine Learning**（Chen 等，O'Reilly）— 将 SRE 模式应用于 ML。

## 实践 + 数据集

- **Kaggle** — [kaggle.com](https://www.kaggle.com/)。竞赛、数据集、kernels。标准的入门级实践平台。
- **Papers with Code** — [paperswithcode.com](https://paperswithcode.com/)。论文附有实现和基准测试。
- **UCI ML Repository** — [archive.ics.uci.edu/ml](https://archive.ics.uci.edu/ml/)。经典小型数据集，适合学习。

## 社区

- **r/MachineLearning** — 偏向研究的 subreddit。有助于跟进新论文。
- **Towards Data Science** — Medium 上的出版物。质量参差不齐；最好的文章非常出色。
- **The Gradient** — [thegradient.pub](https://thegradient.pub/)。长篇 ML 思考文章。

## 关于 ML "基础" 与 AI 基础设施的一点说明

本模块涵盖 ML 基础，因为 AI 基础设施工程师需要能够阅读 ML 代码、理解模型生命周期，并能与 ML 工程师流利沟通。本方向职业发展路径侧重于*基础设施*层（服务、训练、数据、可观测性），而非成为 ML 研究员。使用这些资源来培养流利度，而非深度。
