# Linux 基础 - 推荐资源

## 官方文档

- [Linux 文档项目](https://tldp.org/) - 全面的指南和 HOWTO
- [Ubuntu 官方文档](https://help.ubuntu.com/) - Ubuntu 特定文档
- [Red Hat Enterprise Linux 文档](https://access.redhat.com/documentation/en-us/red_hat_enterprise_linux/) - 企业级 Linux 参考
- [Arch Linux Wiki](https://wiki.archlinux.org/) - 即使对非 Arch 用户也是极好的资源
- Man 手册页 - 可通过 `man` 命令在任何 Linux 系统上获取

## 书籍

### 初学者友好
- **"The Linux Command Line"** - 作者 William Shotts（在 linuxcommand.org 免费在线）
  - 命令行优秀入门
  - 清晰解释，配有实际示例
  - 涵盖 bash 脚本基础

- **"Linux Basics for Hackers"** - 作者 OccupyTheWeb
  - 实用的动手方法
  - 注重安全的视角
  - 适合基础设施工程师

### 中级
- **"Unix and Linux System Administration Handbook"** - 作者 Evi Nemeth、Garth Snyder、Trent R. Hein
  - 全面的系统管理指南
  - 行业标准参考
  - 涵盖现代实践

- **"How Linux Works"** - 作者 Brian Ward
  - 深入 Linux 内部机制
  - 解释 Linux 行为背后的"原因"
  - 非常适合理解架构

### Shell 脚本
- **"Learning the bash Shell"** - 作者 Cameron Newham
  - 全面的 bash 脚本指南
  - 从基础到高级主题
  - 实际示例

- **"Classic Shell Scripting"** - 作者 Arnold Robbins 和 Nelson H.F. Beebe
  - 涵盖 sh、bash 和可移植脚本
  - 高级技巧
  - UNIX 哲学

## Linux 学习技巧

1. **将 Linux 作为日常使用：** 最好的学习方式是经常使用
2. **安全地试错：** 使用 VM 进行尝试，无需担心
3. **阅读 Man 手册页：** 它们全面且权威
4. **加入社区：** 提问并帮助他人
5. **做项目：** 将学到的东西应用到实际问题中
6. **自动化一切：** 练习将日常任务脚本化
7. **理解哲学：** 学习 UNIX 的思维方式
8. **维护命令日志：** 记录新命令及其用途
